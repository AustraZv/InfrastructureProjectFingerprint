This extension has been converted to analysis-only mode and all request blocking / adblocking code has been removed.

TrackHAR integration is wired through trackhar_integration.js, but the actual TrackHAR browser bundle is NOT included in this zip.
To enable real TrackHAR processing, add a browser-compatible bundle before background.js that exposes one of these globals:

- TrackHAR.process
- processHar

Recommended approach:
1. Bundle the npm package `trackhar` for browser use with Rollup, Vite, or esbuild.
2. Output a single file, e.g. `vendor/trackhar.bundle.js`.
3. Add that file to `background.scripts` in manifest.json before `trackhar_integration.js`.

Expected runtime behavior:
- Without the bundle: the extension still logs traffic and performs rule/heuristic analysis.
- With the bundle: the extension also runs TrackHAR against the generated HAR and shows adapter/property hits in the popup.
